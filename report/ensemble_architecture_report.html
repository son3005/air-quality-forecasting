Phân Tích Kiến Trúc Ensemble Model

Tổng Quan

Ensemble = alpha x XLinear + (1 - alpha) x ESTGCN

Đây là mô hình Weighted Average Ensemble — không train model mới, mà kết hợp dự đoán từ 2 model đã train sẵn (XLinear và ESTGCN) với trọng số alpha được tối ưu tự động trên tập validation.

Ensemble không có model riêng. Nó load checkpoint của XLinear và ESTGCN, lấy predictions ra, rồi pha trộn.

2 Model Thành Phần

Model A: XLinear

  • Kiến trúc: Linear projection trên trục thời gian + Gating (TGM/VGM)
  • Đặc điểm: Nhanh, nhẹ, giỏi bắt trend tuyến tính và chu kỳ ngắn
  • Yếu điểm: Không có cơ chế không gian → mỗi trạm dự báo độc lập
  • Train: Riêng cho mỗi (horizon, region), pred_len=1

Model B: ESTGCN

  • Kiến trúc: GraphConv → LSTM → Dense
  • Đặc điểm: GCN học quan hệ không gian giữa các trạm, LSTM học temporal
  • Yếu điểm: Nặng hơn, dự báo toàn bộ 24 bước cùng lúc → không chuyên biệt từng horizon
  • Train: 1 model duy nhất cho mỗi region, pred_len=24

Cơ Chế Grid Search Alpha

for alpha in [0.00, 0.01, 0.02, ..., 1.00]:   # 101 giá trị
    ensemble = alpha * XLinear_val + (1-alpha) * ESTGCN_val
    mae = mean(|ensemble - true_val|)
    if mae < best → lưu alpha
Kết quả alphaÝ nghĩa
alpha ≈ 1.0XLinear gần như thống trị, ESTGCN không hữu ích
alpha ≈ 0.5Hai model bổ trợ nhau tốt
alpha ≈ 0.0ESTGCN thống trị

Trong thực tế benchmark, alpha thường rất gần 1.0 (0.89 – 1.00), nghĩa là XLinear gần như luôn tốt hơn ESTGCN. Ensemble chỉ cải thiện rất nhỏ so với XLinear đơn lẻ.

Tóm Tắt Lý Do Thiết Kế

Quyết địnhLý do
Weighted Average (không phải stacking)Đơn giản, không cần train thêm model thứ 3, tránh overfit trên dataset nhỏ
Grid Search alpha trên ValTìm trọng số tối ưu mà không cần gradient, tránh data leakage từ test set
Per-horizon alphaMỗi horizon có đặc tính khác nhau — alpha có thể thay đổi (ví dụ XLinear tốt hơn ở T+1, ESTGCN có thể tốt hơn ở T+24)
XLinear + ESTGCNKết hợp 2 "góc nhìn" bổ trợ: XLinear = temporal expert (trend, chu kỳ), ESTGCN = spatial expert (lan truyền giữa trạm)
ESTGCN pred_len=24Train 1 lần, dùng cho tất cả horizon → tiết kiệm tài nguyên. Trade-off: kém chuyên biệt
Align min lengthSố sample val/test có thể khác nhau giữa 2 model do cách xây dataset → cần cắt cho bằng nhau

Kết Luận

Ensemble là phương pháp thận trọng và an toàn — nó không bao giờ tệ hơn model tốt nhất trong 2 model thành phần (vì alpha tự điều chỉnh). Tuy nhiên, khi alpha ≈ 1.0 liên tục, điều này cho thấy ESTGCN không đóng góp đáng kể, và Ensemble gần như tương đương XLinear đơn lẻ.
